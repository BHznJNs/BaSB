**B**log **a**s **S**econd **B**rain!

## Getting Started

```shell
npm install basb-cli -g
```

After installed:

```shell
basb-cli create [blog-name]
cd [blog-name]
npm link basb-cli
```

Use `basb-cli` subcommand to preview:

```shell
basb-cli build
basb-cli preview
```
