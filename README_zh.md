是**博**客，也是第二大**脑**！

## 开始使用

```shell
npm install basb-cli -g
```

在安装完成后：

```shell
basb-cli create [博客名称]
cd [博客名称]
npm link basb-cli
```

使用 `basb-cli` 的子命令启用预览服务器：

```shell
basb-cli build
basb-cli preview
```
